## 🌐 Overview

This project is a visually striking, premium responsive landing page centered around a "Cyborg/Cybernetic" theme. It pushes the boundaries of modern UI/UX by heavily relying on interactive CSS/JS effects to create an immersive, futuristic environment. 

## ✨ Key Features & Augmentations

- **Custom Cyber-Cursor**: Replaces the default mouse pointer with an interactive glowing cyan core and a trailing focus ring that expands and shifts colors on interactable elements.
- **Hacker Text Scramble**: Hovering over navigation links triggers a randomized cryptographic text-scramble effect before settling on the target word.
- **Magnetic UI Elements**: Call-to-action buttons feature magnetic pulling physics when your cursor approaches them, increasing engagement and tactile feel.
- **Advanced 3D Hover Parallax**: Augmentation and Timeline cards tilt organically across all 3 axes in response to mouse movement.
- **Dynamic Scroll HUD**: A neon progress bar spans the top of the viewport, calculating scroll depth in real-time.
- **Staggered Scroll Reveals**: Sections, headers, and UI cards fluidly slide and scale into view via a highly optimized 60FPS `IntersectionObserver`.
- **Pure CSS 3D Geometry**: The hero section features an endlessly rotating, glowing 3D geometric cube constructed entirely from CSS `transform-style: preserve-3d`.

## 🛠 Tech Stack

- **HTML5**: Semantic structure and BEM-inspired classes.
- **CSS3 / Vanilla CSS**: No heavy frameworks. Utilizes CSS variables, complex `keyframes`, custom cursors, gradients, and 3D perspectives.
- **Vanilla JavaScript (ES6)**: Lightweight DOM manipulation for magnetic tracking, intersection observing, scrambling algorithms, and matrix particle canvas rendering.

## 🚀 Running Locally

To run this project locally, simply clone the repository and open the HTML file:

```bash
# Clone the repository
git clone https://github.com/parthbadgire-code/tecgfest-cyborg-landing-page.git

# Navigate into the directory
cd tecgfest-cyborg-landing-page

# Open index.html in your default browser
open index.html # On Mac
# start index.html # On Windows
```
